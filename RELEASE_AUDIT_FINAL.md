### ✅ Пункт 2: Безопасный Fallback Пароля
**Статус:** ЗАКРЫТ
- Удалён известный пароль `ChangeMe_2026!`
- Production без `ERP_INITIAL_ADMIN_PASSWORD` теперь завершается с ошибкой
- Локальные тесты настроены на использование `admin` только в E2E конфигурации

### ✅ Пункт 3: Backend-Enforcement Обязательной Смены Пароля
**Статус:** ЗАКРЫТ
- Добавлен middleware в `auth_dependencies.py`
- Пользователи с `must_change_password=true` могут только проверить профиль и сменить пароль
- API операции возвращают 403 для заблокированных пользователей

### ✅ Пункт 4: Безопасность Backup PostgreSQL
**Статус:** ЗАКРЫТ
- Пароль больше не передаётся в аргументах `pg_dump`
- Используется безопасный метод через `PGPASSWORD` environment variable
- Пароль временно файла очищается после использования

### ✅ Пункт 8: Ограничение Скидки Суммой Заказа
**Статус:** ЗАКРЫТ

### ✅ Пункт 9: FIFO-Аудит Многопартийных Продаж
