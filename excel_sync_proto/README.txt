Прототип синхронизации Excel <-> SQLite (локально, одиночный пользователь).

Как использовать:
1) Установите зависимости: pip install -r requirements.txt
2) Поместите workbook "data.xlsx" в ту же папку или запустите sync.py — он создаст пример data.xlsx и data.db
3) Откройте data.xlsx, внесите изменения, сохраните. sync.py отследит сохранение и запишет изменения в SQLite.

Ограничения прототипа:
- Для простоты при изменении файла все листы перезаписываются в соответствующие таблицы в SQLite (to_sql with if_exists='replace').
- Нет сложной логики конфликтов/строковых diff'ов — это упрощённый рабочий пример.
